这是一个使用 [`create-next-app`](https://nextjs.org/docs/app/api-reference/cli/create-next-app) 初始化的 [Next.js](https://nextjs.org) 项目。

## 快速开始

先运行开发服务器：

```bash
npm run dev
# 或者
yarn dev
# 或者
pnpm dev
# 或者
bun dev
```

在浏览器中打开 [http://localhost:3000](http://localhost:3000) 查看效果。

你可以通过修改 `app/page.tsx` 来开始编辑页面。保存后页面会自动刷新。

本项目使用 [`next/font`](https://nextjs.org/docs/app/building-your-application/optimizing/fonts) 自动优化并加载 Vercel 推出的新字体 [Geist](https://vercel.com/font)。

## 深入了解

想了解更多关于 Next.js 的内容，可参考以下资源：

- [Next.js 文档](https://nextjs.org/docs) —— 了解 Next.js 的功能与 API。
- [Learn Next.js](https://nextjs.org/learn) —— 交互式 Next.js 教程。

你也可以访问 [Next.js 官方 GitHub 仓库](https://github.com/vercel/next.js) 提交反馈或贡献代码。

## 部署到 Vercel

部署 Next.js 应用最简单的方式是使用 Next.js 作者打造的 [Vercel 平台](https://vercel.com/new?utm_medium=default-template&filter=next.js&utm_source=create-next-app&utm_campaign=create-next-app-readme)。

查阅 [Next.js 部署文档](https://nextjs.org/docs/app/building-your-application/deploying) 了解更多细节。
