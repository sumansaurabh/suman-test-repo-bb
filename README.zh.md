# suman-test-repo-bb 仓库

欢迎来到 suman-test-repo-bb 项目！

## 项目简介
suman-test-repo-bb 是一个用于演示和测试的示例代码仓库。

## 主要文件
- `src/`：源代码目录
- `public/`：公共资源文件夹
- `package.json`：项目依赖和脚本说明

## 如何运行

1. 安装依赖：
   ```bash
   npm install
   ```
2. 启动项目：
   ```bash
   npm run dev
   ```
