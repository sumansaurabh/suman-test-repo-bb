这是一个基于 [Next.js](https://nextjs.org) 开发的项目，使用 [`create-next-app`](https://nextjs.org/docs/app/api-reference/cli/create-next-app) 初始化。

## 项目简介

这是一个功能完善的货币转换应用，提供以下功能：
- **实时汇率转换**：支持多种全球货币的即时换算。
- **汇率走势图**：直观展示历史汇率波动。
- **市场摘要**：快速查看主要货币对的市场表现。
- **响应式设计**：完美适配各种设备屏幕。

## 开始使用

首先，运行开发服务器：

```bash
npm run dev
# 或
yarn dev
# 或
pnpm dev
# 或
bun dev
```

在浏览器中打开 [http://localhost:3000](http://localhost:3000) 查看结果。

你可以通过修改 `src/app/page.tsx` 开始编辑页面。当你修改文件时，页面会自动更新。

本项目使用 [`next/font`](https://nextjs.org/docs/app/building-your-application/optimizing/fonts) 自动优化并加载 Geist（Vercel 推出的一款新字体）。
