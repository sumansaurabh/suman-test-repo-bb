这是一个使用 [`create-next-app`](https://nextjs.org/docs/app/api-reference/cli/create-next-app) 创建的 [Next.js](https://nextjs.org) 项目。

## 开始使用

首先启动开发服务器：

```bash
npm run dev
# 或者
yarn dev
# 或者
pnpm dev
# 或者
bun dev
```

打开 [http://localhost:3000](http://localhost:3000) 即可在浏览器中查看效果。

你可以从修改 `app/page.tsx` 开始编辑页面，保存后页面会自动热更新。

本项目使用 [`next/font`](https://nextjs.org/docs/app/building-your-application/optimizing/fonts) 来自动优化和加载 [Geist](https://vercel.com/font) 字体。

## 在 Vercel 上部署

部署 Next.js 应用最简单的方式是在 [Vercel 平台](https://vercel.com/new?utm_medium=default-template&filter=next.js&utm_source=create-next-app&utm_campaign=create-next-app-readme) 上完成，它由 Next.js 的创建者构建。

查看 [Next.js 部署文档](https://nextjs.org/docs/app/building-your-application/deploying) 以获取更多详情。
