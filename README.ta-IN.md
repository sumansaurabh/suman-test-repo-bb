இது [`create-next-app`](https://nextjs.org/docs/app/api-reference/cli/create-next-app) மூலம் துவக்கப்பட்ட ஒரு [Next.js](https://nextjs.org) திட்டம்.

## தொடங்குதல்

முதலில், டெவலப்மென்ட் சர்வரை இயக்கவும்:

```bash
npm run dev
# அல்லது
yarn dev
# அல்லது
pnpm dev
# அல்லது
bun dev
```

உங்கள் உலாவியில் [http://localhost:3000](http://localhost:3000) ஐத் திறந்து முடிவைக் காணலாம்.

`app/page.tsx` ஐ மாற்றுவதன் மூலம் பக்கத்தைத் திருத்தத் தொடங்கலாம். நீங்கள் கோப்பைத் திருத்தும்போது பக்கம் தானாகவே புதுப்பிக்கப்படும்.

இந்தத் திட்டம் [`next/font`](https://nextjs.org/docs/app/building-your-application/optimizing/fonts) ஐப் பயன்படுத்தி [Geist](https://vercel.com/font), Vercel க்கான புதிய எழுத்துரு குடும்பத்தை தானாகவே மேம்படுத்தி ஏற்றுகிறது.

## மேலும் அறிக

Next.js பற்றி மேலும் அறிய, பின்வரும் ஆதாரங்களைப் பார்க்கவும்:

- [Next.js ஆவணங்கள்](https://nextjs.org/docs) - Next.js அம்சங்கள் மற்றும் API பற்றி அறிக.
- [Next.js ஐக் கற்றுக்கொள்ளுங்கள்](https://nextjs.org/learn) - ஒரு ஊடாடும் Next.js பயிற்சி.

நீங்கள் [Next.js GitHub களஞ்சியத்தைப்](https://github.com/vercel/next.js) பார்க்கலாம் - உங்கள் கருத்து மற்றும் பங்களிப்புகள் வரவேற்கப்படுகின்றன!
