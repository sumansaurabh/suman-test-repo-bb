Huu ni mradi wa [Next.js](https://nextjs.org) ulioanzishwa na [`create-next-app`](https://nextjs.org/docs/app/api-reference/cli/create-next-app).

## Kuanza

Kwanza, endesha seva ya ukuzaji:

```bash
npm run dev
# au
yarn dev
# au
pnpm dev
# au
bun dev
```

Fungua [http://localhost:3000](http://localhost:3000) na kivinjari chako ili kuona matokeo.

Unaweza kuanza kuhariri ukurasa kwa kurekebisha `app/page.tsx`. Ukurasa hujisasisha kiotomatiki unavyohariri faili.

Mradi huu unatumia [`next/font`](https://nextjs.org/docs/app/building-your-application/optimizing/fonts) kuboresha na kupakia kiotomatiki [Geist](https://vercel.com/font), familia mpya ya fonti kwa Vercel.

## Jifunze Zaidi

Ili kujifunza zaidi kuhusu Next.js, angalia rasilimali zifuatazo:

- [Nyaraka za Next.js](https://nextjs.org/docs) - jifunze kuhusu vipengele na API ya Next.js.
- [Jifunze Next.js](https://nextjs.org/learn) - mafunzo shirikishi ya Next.js.

Unaweza kuangalia [hazina ya Next.js GitHub](https://github.com/vercel/next.js) - maoni na michango yako inakaribishwa!

## Tumia kwenye Vercel

Njia rahisi zaidi ya kupeleka programu yako ya Next.js ni kutumia [Jukwaa la Vercel](https://vercel.com/new?utm_medium=default-template&filter=next.js&utm_source=create-next-app&utm_campaign=create-next-app-readme) kutoka kwa waumbaji wa Next.js.

Angalia [nyaraka zetu za uwekaji wa Next.js](https://nextjs.org/docs/app/building-your-application/deploying) kwa maelezo zaidi.
