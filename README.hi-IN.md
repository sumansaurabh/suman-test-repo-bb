यह एक [Next.js](https://nextjs.org) प्रोजेक्ट है जिसे [`create-next-app`](https://nextjs.org/docs/app/api-reference/cli/create-next-app) के साथ बूटस्ट्रैप किया गया है।

## शुरू करना

सबसे पहले, डेवलपमेंट सर्वर चलाएँ:

```bash
npm run dev
# या
yarn dev
# या
pnpm dev
# या
bun dev
```

परिणाम देखने के लिए अपने ब्राउज़र के साथ [http://localhost:3000](http://localhost:3000) खोलें।

आप `app/page.tsx` को संशोधित करके पेज को संपादित करना शुरू कर सकते हैं। फ़ाइल को संपादित करते ही पेज स्वतः अपडेट हो जाता है।

यह प्रोजेक्ट [`next/font`](https://nextjs.org/docs/app/building-your-application/optimizing/fonts) का उपयोग [Geist](https://vercel.com/font), Vercel के लिए एक नया फ़ॉन्ट परिवार, को स्वचालित रूप से अनुकूलित और लोड करने के लिए करता है।

## और जानें

Next.js के बारे में अधिक जानने के लिए, निम्नलिखित संसाधनों पर एक नज़र डालें:

- [Next.js डॉक्यूमेंटेशन](https://nextjs.org/docs) - Next.js सुविधाओं और API के बारे में जानें।
- [Next.js सीखें](https://nextjs.org/learn) - एक इंटरैक्टिव Next.js ट्यूटोरियल।

आप [Next.js GitHub रिपॉजिटरी](https://github.com/vercel/next.js) देख सकते हैं - आपकी प्रतिक्रिया और योगदान का स्वागत है!

## Vercel पर डिप्लॉय करें

अपने Next.js ऐप को डिप्लॉय करने का सबसे आसान तरीका Next.js के रचनाकारों के [Vercel प्लेटफ़ॉर्म](https://vercel.com/new?utm_medium=default-template&filter=next.js&utm_source=create-next-app&utm_campaign=create-next-app-readme) का उपयोग करना है।

अधिक जानकारी के लिए हमारे [Next.js डिप्लॉयमेंट डॉक्यूमेंटेशन](https://nextjs.org/docs/app/building-your-application/deploying) को देखें।
