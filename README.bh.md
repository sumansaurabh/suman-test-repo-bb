ਈ एगो [Next.js](https://nextjs.org) प्रोजेक्ट ह जवना के [`create-next-app`](https://nextjs.org/docs/app/api-reference/cli/create-next-app) से बूस्टस्ट्रैप कइल गइल बा.

## शुरू करे खातिर

सबसे पहिले, डेवलपमेंट सर्वर चलाईं:

```bash
npm run dev
# या
yarn dev
# या
pnpm dev
# या
bun dev
```

रिजल्ट देखे खातिर आपन ब्राउज़र से [http://localhost:3000](http://localhost:3000) खोलीं.

आप `app/page.tsx` के बदल के पेज एडिट कइल शुरू क सकत बानी. जइसे ही आप फाइल एडिट करब, पेज अपने आप अपडेट हो जाई.

ई प्रोजेक्ट [`next/font`](https://nextjs.org/docs/app/building-your-application/optimizing/fonts) के इस्तेमाल करेला ताकि [Geist](https://vercel.com/font), जवन Vercel खातिर एगो नया फॉन्ट फैमिली ह, के अपने आप ऑप्टिमाइज आ लोड कइल जा सके.

## अउरी जानीं

Next.js के बारे में अउरी जाने खातिर, नीचे दिहल गइल रिसोर्स सभ के देखीं:

- [Next.js डॉक्यूमेंटेशन](https://nextjs.org/docs) - Next.js के फीचर्स आ API के बारे में जानीं.
- [Next.js सीखीं](https://nextjs.org/learn) - एगो इंटरैक्टिव Next.js ट्यूटोरियल.

आप [Next.js GitHub रिपॉजिटरी](https://github.com/vercel/vercel.js) के देख सकत बानी - आपके फीडबैक आ योगदान के स्वागत बा!

## Vercel पर डिप्लॉय करीं

आपन Next.js ऐप डिप्लॉय करे के सबसे आसान तरीका ह [Vercel प्लेटफॉर्म](https://vercel.com/new?utm_medium=default-template&filter=next.js&utm_source=create-next-app&utm_campaign=create-next-app-readme) के इस्तेमाल कइल, जवन Next.js के क्रिएटर लोगन द्वारा बनावल गइल बा.

अउरी जानकारी खातिर हमार [Next.js डिप्लॉयमेंट डॉक्यूमेंटेशन](https://nextjs.org/docs/app/building-your-application/deploying) देखीं.
