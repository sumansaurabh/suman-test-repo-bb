ഇത് [`create-next-app`](https://nextjs.org/docs/app/api-reference/cli/create-next-app) ഉപയോഗിച്ച് ആരംഭിച്ച ഒരു [Next.js](https://nextjs.org) പ്രോജക്റ്റാണ്.

## തുടങ്ങാം

ആദ്യം, ഡെവലപ്‌മെന്റ് സെർവർ പ്രവർത്തിപ്പിക്കുക:

```bash
npm run dev
# അല്ലെങ്കിൽ
yarn dev
# അല്ലെങ്കിൽ
pnpm dev
# അല്ലെങ്കിൽ
bun dev
```

ഫലം കാണുന്നതിന് നിങ്ങളുടെ ബ്രൗസറിൽ [http://localhost:3000](http://localhost:3000) തുറക്കുക.

`app/page.tsx` പരിഷ്‌ക്കരിച്ചുകൊണ്ട് നിങ്ങൾക്ക് പേജ് എഡിറ്റുചെയ്യാൻ ആരംഭിക്കാം. നിങ്ങൾ ഫയൽ എഡിറ്റുചെയ്യുമ്പോൾ പേജ് യാന്ത്രികമായി അപ്‌ഡേറ്റുചെയ്യുന്നു.

Vercel-ന്റെ പുതിയ ഫോണ്ട് ഫാമിലിയായ [Geist](https://vercel.com/font) യാന്ത്രികമായി ഒപ്റ്റിമൈസ് ചെയ്യാനും ലോഡ് ചെയ്യാനും ഈ പ്രോജക്റ്റ് [`next/font`](https://nextjs.org/docs/app/building-your-application/optimizing/fonts) ഉപയോഗിക്കുന്നു.
