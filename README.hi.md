यह एक [Next.js](https://nextjs.org) प्रोजेक्ट है जो [`create-next-app`](https://nextjs.org/docs/app/api-reference/cli/create-next-app) के साथ शुरू किया गया है।

## शुरुआत करें

पहले, विकास सर्वर चलाएं:

```bash
npm run dev
# या
yarn dev
# या
pnpm dev
# या
bun dev
```

अपने ब्राउज़र में [http://localhost:3000](http://localhost:3000) खोलकर परिणाम देखें।

आप `app/page.tsx` को संशोधित करके पृष्ठ को संपादित करना शुरू कर सकते हैं। पृष्ठ जैसे ही आप फ़ाइल को संपादित करते हैं, स्वचालित रूप से अपडेट हो जाता है।

यह प्रोजेक्ट [`next/font`](https://nextjs.org/docs/app/building-your-application/optimizing/fonts) का उपयोग करता है जो स्वचालित रूप से [Geist](https://vercel.com/font) को अनुकूलित और लोड करता है, जो Vercel के लिए एक नया फॉन्ट फैमिली है।

## अधिक जानें

Next.js के बारे में अधिक जानने के लिए, निम्नलिखित संसाधनों को देखें:

- [Next.js दस्तावेज़](https://nextjs.org/docs) - Next.js की विशेषताओं और API के बारे में जानें।
- [Next.js सीखें](https://nextjs.org/learn) - एक इंटरैक्टिव Next.js ट्यूटोरियल।

आप [Next.js GitHub रिपॉजिटरी](https://github.com/vercel/next.js) को देख सकते हैं - आपके फीडबैक और योगदान का स्वागत है!

## Vercel पर तैनात करें

Next.js ऐप को तैनात करने का सबसे आसान तरीका Next.js के निर्माताओं द्वारा [Vercel Platform](https://vercel.com/new?utm_medium=default-template&filter=next.js&utm_source=create-next-app&utm_campaign=create-next-app-readme) का उपयोग करना है।

अधिक विवरण के लिए हमारे [Next.js तैनाती दस्तावेज़](https://nextjs.org/docs/app/building-your-application/deploying) को देखें।
