# नमस्ते!

यह एक नेक्स्ट.जेएस (Next.js) प्रोजेक्ट है।

## शुरुआत कैसे करें

डेवलपमेंट सर्वर शुरू करने के लिए, यह कमांड चलाएं:

```bash
npm run dev
```

अपने ब्राउज़र में [http://localhost:3000](http://localhost:3000) खोलें।

नेक्स्ट.जेएस के बारे में अधिक जानने के लिए, इन संसाधनों को देखें:

- [नेक्स्ट.जेएस सीखें](https://nextjs.org/learn)
