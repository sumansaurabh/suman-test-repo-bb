यह एक [Next.js](https://nextjs.org) प्रोजेक्ट है जो [`create-next-app`](https://nextjs.org/docs/app/api-reference/cli/create-next-app) के साथ बूटस्ट्रैप किया गया है।

## शुरुआत करें

पहले, डेवलपमेंट सर्वर चलाएं:

```bash
npm run dev
# या
yarn dev
# या
pnpm dev
# या
bun dev
```

अपने ब्राउज़र में [http://localhost:3000](http://localhost:3000) खोलें और परिणाम देखें।

आप `app/page.tsx` को संशोधित करके पेज को संपादित करना शुरू कर सकते हैं। फ़ाइल को संपादित करने पर पेज स्वचालित रूप से अपडेट होगा।

यह प्रोजेक्ट [`next/font`](https://nextjs.org/docs/app/building-your-application/optimizing/fonts) का उपयोग करता है जो [Geist](https://vercel.com/font) को स्वचालित रूप से अनुकूलित और लोड करता है, जो Vercel के लिए एक नई फॉन्ट फैमिली है।

## अधिक जानें

Next.js के बारे में अधिक जानने के लिए, निम्नलिखित संसाधनों को देखें:

- [Next.js डॉक्यूमेंटेशन](https://nextjs.org/docs) - Next.js सुविधाओं और API के बारे में जानें।
- [Next.js सीखें](https://nextjs.org/learn) - एक इंटरैक्टिव Next.js ट्यूटोरियल।

आप [Next.js GitHub रिपोजिटरी](https://github.com/vercel/next.js) को देख सकते हैं - आपकी प्रतिक्रिया और योगदान स्वागत हैं!

## Vercel पर परिनियोजित करें

Next.js ऐप को तैनात करने का सबसे आसान तरीका [Vercel Platform](https://vercel.com/new?utm_medium=default-template&filter=next.js&utm_source=create-next-app&utm_campaign=create-next-app-readme) का उपयोग करना है जो Next.js के निर्माताओं द्वारा बनाया गया है।

अधिक जानकारी के लिए हमारे [Next.js परिनियोजन डॉक्यूमेंटेशन](https://nextjs.org/docs/app/building-your-application/deploying) को देखें।
