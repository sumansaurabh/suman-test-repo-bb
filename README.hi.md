# नमस्ते दुनिया!

यह एक मुद्रा परिवर्तक एप्लिकेशन है।

## सुविधाएँ
* मुद्राओं को परिवर्तित करें
* विनिमय दरें देखें
* ऐतिहासिक डेटा

## सेटअप
1. इस रिपॉजिटरी को क्लोन करें:
   ```bash
   git clone https://github.com/sumansaurabh/suman-test-repo-bb.git
   ```
2. प्रोजेक्ट डायरेक्टरी में नेविगेट करें:
   ```bash
   cd suman-test-repo-bb
   ```
3. निर्भरताएँ स्थापित करें:
   ```bash
   npm install
   ```
4. डेवलपमेंट सर्वर चलाएँ:
   ```bash
   npm run dev
   ```
