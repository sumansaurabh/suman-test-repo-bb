# सुमन टेस्ट रेपो

यह एक [Next.js](https://nextjs.org) प्रोजेक्ट है जो [`create-next-app`](https://nextjs.org/docs/app/api-reference/cli/create-next-app) से शुरू किया गया है।

## शुरुआत करें

पहले, डेवलपमेंट सर्वर चलाएं:

```bash
npm run dev
# या
yarn dev
# या
pnpm dev
# या
bun dev
```

अपने ब्राउज़र में [http://localhost:3000](http://localhost:3000) खोलें और परिणाम देखें।

आप `app/page.tsx` को संपादित करके पृष्ठ को संपादित करना शुरू कर सकते हैं। फ़ाइल को संपादित करते समय पृष्ठ स्वचालित रूप से अपडेट होता है।

यह प्रोजेक्ट [`next/font`](https://nextjs.org/docs/app/building-your-application/optimizing/fonts) का उपयोग करता है जो स्वचालित रूप से [Geist](https://vercel.com/font) को अनुकूलित और लोड करता है, जो Vercel के लिए एक नई फ़ॉन्ट परिवार है।

## अधिक जानें

Next.js के बारे में अधिक जानने के लिए, निम्नलिखित संसाधनों को देखें:

- [Next.js दस्तावेज़](https://nextjs.org/docs) - Next.js फीचर्स और API के बारे में जानें।
- [Next.js सीखें](https://nextjs.org/learn) - एक इंटरैक्टिव Next.js ट्यूटोरियल।

आप [Next.js GitHub रिपोजिटरी](https://github.com/vercel/next.js) को देख सकते हैं - आपकी प्रतिक्रिया और योगदान स्वागत है!

## Vercel पर तैनाती

Next.js ऐप को तैनात करने का सबसे आसान तरीका Next.js के निर्माताओं द्वारा [Vercel Platform](https://vercel.com/new?utm_medium=default-template&filter=next.js&utm_source=create-next-app&utm_campaign=create-next-app-readme) का उपयोग करना है।

अधिक विवरण के लिए हमारे [Next.js तैनाती दस्तावेज़](https://nextjs.org/docs/app/building-your-application/deploying) को देखें।
