## தொடங்குதல்

முதலில், மேம்பாட்டு சேவையகத்தை இயக்கவும்:

```bash
npm run dev
# அல்லது
yarn dev
# அல்லது
pnpm dev
# அல்லது
bun dev
```

முடிவைக் காண உங்கள் உலாவியில் [http://localhost:3000](http://localhost:3000) ஐத் திறக்கவும்.

`app/page.tsx` ஐ மாற்றுவதன் மூலம் பக்கத்தைத் திருத்தத் தொடங்கலாம். நீங்கள் கோப்பைத் திருத்தும்போது பக்கம் தானாகவே புதுப்பிக்கப்படும்.

இந்தத் திட்டம் [`next/font`](https://nextjs.org/docs/app/building-your-application/optimizing/fonts) ஐப் பயன்படுத்தி [Geist](https://vercel.com/font) ஐ தானாகவே மேம்படுத்தி ஏற்றுகிறது, இது Vercel க்கான புதிய எழுத்துரு குடும்பம்.

## மேலும் அறிக

Next.js பற்றி மேலும் அறிய, பின்வரும் ஆதாரங்களைப் பார்க்கவும்:

- [Next.js ஆவணப்படுத்தல்](https://nextjs.org/docs) - Next.js அம்சங்கள் மற்றும் API பற்றி அறிக.
- [Next.js ஐக் கற்றுக்கொள்ளுங்கள்](https://nextjs.org/learn) - ஒரு ஊடாடும் Next.js பயிற்சி.

நீங்கள் [Next.js GitHub களஞ்சியத்தைப்](https://github.com/vercel/next.js) பார்க்கலாம் - உங்கள் கருத்துக்களும் பங்களிப்புகளும் வரவேற்கப்படுகின்றன!
