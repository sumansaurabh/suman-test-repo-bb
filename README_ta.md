இது [`create-next-app`](https://nextjs.org/docs/app/api-reference/cli/create-next-app) மூலம் உருவாக்கப்பட்ட ஒரு [Next.js](https://nextjs.org) திட்டமாகும்.

## தொடங்குதல்

முதலில், மேம்பாட்டு சேவையகத்தை இயக்கவும்:

```bash
npm run dev
# அல்லது
yarn dev
# அல்லது
pnpm dev
# அல்லது
bun dev
```

முடிவைக் காண உங்கள் உலாவியில் [http://localhost:3000](http://localhost:3000) ஐத் திறக்கவும்.

`app/page.tsx` ஐ மாற்றியமைப்பதன் மூலம் நீங்கள் பக்கத்தைத் திருத்தத் தொடங்கலாம். நீங்கள் கோப்பைத் திருத்தும்போது பக்கம் தானாகவே புதுப்பிக்கப்படும்.

இந்தத் திட்டம் Vercel இன் புதிய எழுத்துருக் குடும்பமான [Geist](https://vercel.com/font) ஐ தானாகவே மேம்படுத்தவும் ஏற்றவும் [`next/font`](https://nextjs.org/docs/app/building-your-application/optimizing/fonts) ஐப் பயன்படுத்துகிறது.

## மேலும் அறிக

Next.js பற்றி மேலும் அறிய, பின்வரும் வளங்களைப் பார்க்கவும்:

- [Next.js ஆவணங்கள்](https://nextjs.org/docs) - Next.js அம்சங்கள் மற்றும் API பற்றி அறிக.
- [Next.js கற்க](https://nextjs.org/learn) - ஒரு ஊடாடும் Next.js பயிற்சி.

நீங்கள் [Next.js GitHub களஞ்சியத்தை](https://github.com/vercel/next.js) பார்க்கலாம் - உங்கள் கருத்துக்களும் பங்களிப்புகளும் வரவேற்கப்படுகின்றன!
