இது [`create-next-app`](https://nextjs.org/docs/app/api-reference/cli/create-next-app) ஐப் பயன்படுத்தி உருவாக்கப்பட்ட ஒரு [Next.js](https://nextjs.org) செயல்திட்டம் (project).

## தொடங்குதல்

முதலில், development server-ஐ இயக்கவும்:

```bash
npm run dev
# அல்லது
yarn dev
# அல்லது
pnpm dev
# அல்லது
bun dev
```

முடிவை அறிய உங்கள் browser-இல் [http://localhost:3000](http://localhost:3000) ஐத் திறக்கவும்.

`app/page.tsx` கோப்பை (file) திருத்துவதன் மூலம் நீங்கள் பக்கத்தைத் திருத்தத் தொடங்கலாம். நீங்கள் கோப்பைத் திருத்தும்போது பக்கம் தானாகவே புதுப்பிக்கப்படும் (auto-updates).

இந்தத் திட்டம் Vercel-க்கான புதிய எழுத்துருக் குடும்பமான (font family) [Geist](https://vercel.com/font)-ஐத் தானாக மேம்படுத்தவும் ஏற்றவும் [`next/font`](https://nextjs.org/docs/app/building-your-application/optimizing/fonts)-ஐப் பயன்படுத்துகிறது.

## மேலும் அறிக

Next.js பற்றி மேலும் அறிய, பின்வரும் வளங்களைப் பார்க்கவும்:

- [Next.js ஆவணங்கள் (Documentation)](https://nextjs.org/docs) - Next.js அம்சங்கள் மற்றும் API பற்றி அறிய.
- [Next.js கற்க](https://nextjs.org/learn) - ஒரு ஊடாடும் (interactive) Next.js டுடோரியல்.

நீங்கள் [Next.js GitHub களஞ்சியத்தை (repository)](https://github.com/vercel/next.js) பார்க்கலாம் - உங்கள் கருத்துக்களும் பங்களிப்புகளும் வரவேற்கப்படுகின்றன!

## Vercel இல் Deploy செய்தல்

உங்கள் Next.js செயலியை (app) deploy செய்ய எளிதான வழி, Next.js-ஐ உருவாக்கியவர்களின் [Vercel Platform](https://vercel.com/new?utm_medium=default-template&filter=next.js&utm_source=create-next-app&utm_campaign=create-next-app-readme)-ஐப் பயன்படுத்துவதாகும்.

மேலும் விவரங்களுக்கு எங்கள் [Next.js deployment ஆவணங்களைப்](https://nextjs.org/docs/app/building-your-application/deploying) பார்க்கவும்.
