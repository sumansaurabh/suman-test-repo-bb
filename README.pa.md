ਇਹ ਇੱਕ [Next.js](https://nextjs.org) ਪ੍ਰੋਜੈਕਟ ਹੈ ਜੋ [`create-next-app`](https://nextjs.org/docs/app/api-reference/cli/create-next-app) ਨਾਲ ਬੂਟਸਟਰੈਪ ਕੀਤਾ ਗਿਆ ਹੈ।

## ਸ਼ੁਰੂਆਤ ਕਰਨਾ

ਪਹਿਲਾਂ, ਡਿਵੈਲਪਮੈਂਟ ਸਰਵਰ ਚਲਾਓ:

```bash
npm run dev
# ਜਾਂ
yarn dev
# ਜਾਂ
pnpm dev
# ਜਾਂ
bun dev
```

ਨਤੀਜਾ ਦੇਖਣ ਲਈ ਆਪਣੇ ਬ੍ਰਾਊਜ਼ਰ ਨਾਲ [http://localhost:3000](http://localhost:3000) ਖੋਲ੍ਹੋ।

ਤੁਸੀਂ `app/page.tsx` ਨੂੰ ਸੋਧ ਕੇ ਪੰਨੇ ਨੂੰ ਸੰਪਾਦਿਤ ਕਰਨਾ ਸ਼ੁਰੂ ਕਰ ਸਕਦੇ ਹੋ। ਜਿਵੇਂ ਹੀ ਤੁਸੀਂ ਫਾਈਲ ਨੂੰ ਸੰਪਾਦਿਤ ਕਰਦੇ ਹੋ, ਪੰਨਾ ਆਪਣੇ ਆਪ ਅੱਪਡੇਟ ਹੋ ਜਾਂਦਾ ਹੈ।

ਇਹ ਪ੍ਰੋਜੈਕਟ [`next/font`](https://nextjs.org/docs/app/building-your-application/optimizing/fonts) ਦੀ ਵਰਤੋਂ ਕਰਦਾ ਹੈ ਤਾਂ ਜੋ [Geist](https://vercel.com/font), Vercel ਲਈ ਇੱਕ ਨਵਾਂ ਫੌਂਟ ਪਰਿਵਾਰ, ਨੂੰ ਆਪਣੇ ਆਪ ਅਨੁਕੂਲ ਬਣਾਇਆ ਜਾ ਸਕੇ ਅਤੇ ਲੋਡ ਕੀਤਾ ਜਾ ਸਕੇ।

- [Next.js ਸਿੱਖੋ](https://nextjs.org/learn) - ਇੱਕ ਇੰਟਰਐਕਟਿਵ Next.js ਟਿਊਟੋਰਿਅਲ।
