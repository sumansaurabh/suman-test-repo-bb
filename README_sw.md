Huu ni mradi wa [Next.js](https://nextjs.org) ulioanzishwa na [`create-next-app`](https://nextjs.org/docs/app/api-reference/cli/create-next-app).

## Kuanza

Kwanza, endesha seva ya maendeleo (development server):

```bash
npm run dev
# au
yarn dev
# au
pnpm dev
# au
bun dev
```

Fungua [http://localhost:3000](http://localhost:3000) kwenye kivinjari chako ili kuona matokeo.

Unaweza kuanza kuhariri ukurasa kwa kurekebisha `app/page.tsx`. Ukurasa hujisasisha kiotomatiki unapo hariri faili.

Mradi huu unatumia [`next/font`](https://nextjs.org/docs/app/building-your-application/optimizing/fonts) ili kuboresha na kupakia [Geist](https://vercel.com/font), familia mpya ya fonti ya Vercel.

## Jifunze Zaidi

Ili kujifunza zaidi kuhusu Next.js, angalia nyenzo zifuatazo:

- [Nyaraka za Next.js](https://nextjs.org/docs) - jifunze kuhusu vipengele na API ya Next.js.
- [Jifunze Next.js](https://nextjs.org/learn) - mafunzo ya Next.js yanayoshirikisha.

Unaweza kuangalia [hifadhi ya GitHub ya Next.js](https://github.com/vercel/next.js) - maoni na michango yako inakaribishwa!

## Sambaza kwenye Vercel

Njia rahisi zaidi ya kusambaza programu yako ya Next.js ni kutumia [Jukwaa la Vercel](https://vercel.com/new?utm_medium=default-template&filter=next.js&utm_source=create-next-app&utm_campaign=create-next-app-readme) kutoka kwa waundaji wa Next.js.

Angalia [nyaraka zetu za usambazaji za Next.js](https://nextjs.org/docs/app/building-your-application/deploying) kwa maelezo zaidi.
