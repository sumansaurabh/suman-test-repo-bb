यह एक [Next.js](https://nextjs.org) प्रोजेक्ट है जिसे [`create-next-app`](https://nextjs.org/docs/app/api-reference/cli/create-next-app) के साथ बूटस्ट्रैप किया गया है।

## शुरुआत करें

पहले, डेवलपमेंट सर्वर चलाएं:

```bash
npm run dev
# या
yarn dev
# या
pnpm dev
# या
bun dev
```

अपने ब्राउज़र में [http://localhost:3000](http://localhost:3000) खोलें परिणाम देखने के लिए।

आप `app/page.tsx` फ़ाइल को संपादित करके पेज को संपादित करना शुरू कर सकते हैं। पेज आपके संपादन के अनुसार स्वचालित रूप से अपडेट होता है।

यह प्रोजेक्ट [`next/font`](https://nextjs.org/docs/app/building-your-application/optimizing/fonts) का उपयोग करता है ताकि [Geist](https://vercel.com/font) को स्वचालित रूप से अनुकूलित और लोड किया जा सके, जो Vercel के लिए एक नया फ़ॉन्ट परिवार है।

## और जानें

Next.js के बारे में अधिक जानने के लिए निम्नलिखित संसाधनों को देखें:

- [Next.js दस्तावेज](https://nextjs.org/docs) - Next.js की सुविधाओं और API के बारे में जानें।
- [Next.js सीखें](https://nextjs.org/learn) - एक इंटरैक्टिव Next.js ट्यूटोरियल।

आप [Next.js GitHub रिपॉजिटरी](https://github.com/vercel/next.js) को देख सकते हैं - आपकी प्रतिक्रिया और योगदान स्वागत है!

## Vercel पर तैनात करें

अपने Next.js ऐप को तैनात करने का सबसे आसान तरीका Next.js के निर्माताओं द्वारा [Vercel प्लेटफॉर्म](https://vercel.com/new?utm_medium=default-template&filter=next.js&utm_source=create-next-app&utm_campaign=create-next-app-readme) का उपयोग करना है।

अधिक विवरण के लिए हमारे [Next.js डिप्लॉयमेंट दस्तावेज](https://nextjs.org/docs/app/building-your-application/deploying) को देखें।
