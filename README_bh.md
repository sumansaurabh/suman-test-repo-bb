ई एक ठो [Next.js](https://nextjs.org) प्रोजेक्ट ह जे [`create-next-app`](https://nextjs.org/docs/app/api-reference/cli/create-next-app) के साथ शुरू भइल बा।

## शुरुआत करीं

सबसे पहले, डेवलपमेंट सर्वर चलाईं:

```bash
npm run dev
# या
yarn dev
# या
pnpm dev
# या
bun dev
```

परिणाम देखे खातिर अपना ब्राउज़र में [http://localhost:3000](http://localhost:3000) खोलीं।

रउआ `app/page.tsx` के बदल के पेज एडिट कईल शुरू कर सकत बानी। जइसहीं रउआ फाइल एडिट करब, पेज अपने आप अपडेट हो जाई।

ई प्रोजेक्ट [Geist](https://vercel.com/font) के अपने आप ऑप्टिमाइज करे अउरी लोड करे खातिर [`next/font`](https://nextjs.org/docs/app/building-your-application/optimizing/fonts) के इस्तेमाल करेला, जे Vercel खातिर एक ठो नया फॉन्ट परिवार ह।

## अउरी सीखीं

Next.js के बारे में अउरी जाने खातिर, नीचे दिहल गइल संसाधन देख सकत बानी:

- [Next.js डॉक्यूमेंटेशन](https://nextjs.org/docs) - Next.js के फीचर्स अउरी API के बारे में सीखीं।
- [Next.js सीखीं](https://nextjs.org/learn) - एक ठो इंटरैक्टिव Next.js ट्यूटोरियल।

रउआ [Next.js GitHub रिपॉजिटरी](https://github.com/vercel/next.js) देख सकत बानी - रउआ के राय अउरी योगदान के स्वागत बा!

## Vercel पर परिनियोजन (Deploy) करीं

अपने Next.js ऐप के डिप्लॉय करे के सबसे आसान तरीका [Vercel प्लेटफॉर्म](https://vercel.com/new?utm_medium=default-template&filter=next.js&utm_source=create-next-app&utm_campaign=create-next-app-readme) के इस्तेमाल कईल बा, जे Next.js के निर्माता लोग बनवले बा।

अउरी जानकारी खातिर हमनी के [Next.js डिप्लॉयमेंट डॉक्यूमेंटेशन](https://nextjs.org/docs/app/building-your-application/deploying) देखीं।
