ई [Next.js](https://nextjs.org) के प्रोजेक्ट ह जवन [`create-next-app`](https://nextjs.org/docs/app/api-reference/cli/create-next-app) के साथे शुरू कइल गइल बा।

## शुरू करीं

सबसे पहिले, डेवलपमेंट सर्वर चलावे के परी:

```bash
npm run dev
# या
yarn dev
# या
pnpm dev
# या
bun dev
```

नतीजा देखे खातिर अपना ब्राउज़र में [http://localhost:3000](http://localhost:3000) खोलीं।

रउरा `app/page.tsx` के बदल के पेज के एडिट कइल शुरू कर सकत बानी। जइसे-जइसे रउरा फाइल एडिट करब, पेज अपने आप अपडेट हो जाई।

ई प्रोजेक्ट [`next/font`](https://nextjs.org/docs/app/building-your-application/optimizing/fonts) के इस्तेमाल करेला ताकि Vercel खातिर नया फॉन्ट परिवार [Geist](https://vercel.com/font) के अपने आप ऑप्टिमाइज आ लोड कइल जा सके।

## अउरी जानीं

Next.js के बारे में अउरी जाने खातिर, ई सब रिसोर्स देख सकत बानी:

- [Next.js डॉक्यूमेंटेशन](https://nextjs.org/docs) - Next.js के फीचर्स आ API के बारे में सीखीं।
- [Next.js सीखीं](https://nextjs.org/learn) - एगो इंटरैक्टिव Next.js ट्यूटोरियल।

रउरा [Next.js GitHub रिपोजिटरी](https://github.com/vercel/next.js) देख सकत बानी - रउरा राय आ योगदान के स्वागत बा!

## Vercel पर डिप्लॉय करीं

अपने Next.js ऍप के डिप्लॉय करे के सबसे आसान तरीका बा [Vercel प्लेटफॉर्म](https://vercel.com/new?utm_medium=default-template&filter=next.js&utm_source=create-next-app&utm_campaign=create-next-app-readme) के इस्तेमाल कइल, जे Next.js के बनावे वाला लोग ह।

अउरी जानकारी खातिर हमनी के [Next.js डिप्लॉयमेंट डॉक्यूमेंटेशन](https://nextjs.org/docs/app/building-your-application/deploying) देखीं।
