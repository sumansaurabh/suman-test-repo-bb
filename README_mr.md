हा एक [Next.js](https://nextjs.org) प्रकल्प आहे जो [`create-next-app`](https://nextjs.org/docs/app/api-reference/cli/create-next-app) सह बूटस्ट्रॅप केला आहे.

## सुरुवात करत आहे

प्रथम, डेव्हलपमेंट सर्व्हर चालवा:

```bash
npm run dev
# किंवा
yarn dev
# किंवा
pnpm dev
# किंवा
bun dev
```

परिणाम पाहण्यासाठी आपल्या ब्राउझरसह [http://localhost:3000](http://localhost:3000) उघडा.

आपण `app/page.tsx` सुधारित करून पृष्ठ संपादित करणे सुरू करू शकता. आपण फाइल संपादित करताच पृष्ठ स्वयंचलितपणे अद्यतनित होते.

हा प्रकल्प [Geist](https://vercel.com/font) स्वयंचलितपणे ऑप्टिमाइझ करण्यासाठी आणि लोड करण्यासाठी [`next/font`](https://nextjs.org/docs/app/building-your-application/optimizing/fonts) वापरतो, जे Vercel साठी एक नवीन फॉन्ट कुटुंब आहे.

## अधिक जाणून घ्या

Next.js बद्दल अधिक जाणून घेण्यासाठी, खालील संसाधने पहा:

- [Next.js दस्तऐवजीकरण](https://nextjs.org/docs) - Next.js वैशिष्ट्ये आणि API बद्दल जाणून घ्या.
- [Next.js शिका](https://nextjs.org/learn) - एक परस्परसंवादी Next.js ट्यूटोरियल.

आपण [Next.js GitHub रेपॉजिटरी](https://github.com/vercel/next.js) पाहू शकता - तुमचा अभिप्राय आणि योगदान स्वागतार्ह आहे!

## Vercel वर उपयोजित (Deploy) करा

आपले Next.js ॲप उपयोजित करण्याचा सर्वात सोपा मार्ग म्हणजे Next.js च्या निर्मात्यांकडून [Vercel प्लॅटफॉर्म](https://vercel.com/new?utm_medium=default-template&filter=next.js&utm_source=create-next-app&utm_campaign=create-next-app-readme) वापरणे.

अधिक तपशीलांसाठी आमचे [Next.js उपयोजन दस्तऐवजीकरण](https://nextjs.org/docs/app/building-your-application/deploying) पहा.
