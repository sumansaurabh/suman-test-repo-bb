# ཀོཌ་ཞིབ་འཚོལ་གྱི་གློག་རིགས་

དམིགས་བསལ་གྱི་ལས་འབྲེལ་མང་པོ་ཅིག་ལག་ལེན་འཐབ་སྟེ་ ཡིད་ཆེས་ཀྱི་གཞི་རྟེན་ཐོག་ལས་ ནོར་འཁྲུལ་ཚུ་སེལ་ཐབས་ལུ་ འཐེན་བཏོན་ཞུ་བའི་དོན་ལུ་ རང་བཞིན་གྱིས་ཀོཌ་ཞིབ་འཚོལ་འབདཝ་ཨིན།

## སྤྱིར་བཤད།

ཀོཌ་ཞིབ་འཚོལ་གྱི་གློག་རིགས་འདི་གིས་ འཐེན་བཏོན་ཞུ་བའི་ཞིབ་འཚོལ་འདི་ རང་བཞིན་གྱིས་འབདཝ་ཨིནམ་དང་ དེ་ཡང་ ལས་འབྲེལ་མང་པོ་ཅིག་གཅིག་ཁར་གཞི་བཙུགས་འབད་དེ་ ལྟ་བ་མ་འདྲཝ་ཚུ་གི་ཐོག་ལས་ འགྱུར་བ་ཚུ་རང་དབང་ཐོག་ལས་ཞིབ་འཚོལ་འབདཝ་ཨིན། དེ་གིས་ ཡིད་ཆེས་ཀྱི་གཞི་རྟེན་ཐོག་ལས་ ནོར་འཁྲུལ་ཚུ་སེལ་ཐབས་ལུ་ལག་ལེན་འཐབ་སྟེ་ སྤུས་ཚད་མཐོ་བའི་ ལག་ལེན་འཐབ་ཚུགས་པའི་བསམ་འཆར་ཚུ་རྐྱངམ་གཅིག་བཀོད་ནི་འདི་འགན་ལེན་འབདཝ་ཨིན།

## བཟོ་སྒྲིག

### ཡིད་ཆེས་ཀྱི་ཚད་གཞི་བསྒྲིག་བཟོ་འབད།

སྔོན་སྒྲིག་གཞི་ལྟར་ན་ ཚད་གཞི་ ༨༠ ཨིན། བསྒྲིག་བཟོ་འབད་ནི་གི་དོན་ལུ་ བརྡ་བཀོད་ཡིག་ཆ་ 'commands/code-review.md' ནང་ལུ་བསྒྱུར་བཅོས་འབད།
'''markdown
དཀའ་ངལ་ག་ཅི་ཡང་རུང་ ཚད་གཞི་ ༨༠ ལས་ཉུང་བ་ཚུ་སེལ་འཐུ་འབད།
'''

'80' འདི་ཁྱོད་ཀྱི་དགའ་བའི་ཚད་གཞི་ (0-100) ལུ་བསྒྱུར་བཅོས་འབད།

### ཞིབ་འཚོལ་གྱི་དམིགས་གཏད་བཟོ་སྒྲིག

'commands/code-review.md' བསྒྱུར་བཅོས་འབད་དེ་ ལས་འབྲེལ་གྱི་ལས་འགན་ཚུ་ཁ་སྐོང་ ཡང་ན་ བསྒྱུར་བཅོས་འབད།
 - བདེ་འཇགས་ལུ་དམིགས་གཏད་འབད་བའི་ལས་འབྲེལ་ཚུ་ཁ་སྐོང་འབད།
 - ལས་འབྲེལ་ཞིབ་འཚོལ་གྱི་ལས་འབྲེལ་ཚུ་ཁ་སྐོང་འབད།
 - ལག་ལེན་འཐབ་ཚུགས་པའི་ཞིབ་འཚོལ་ལས་འབྲེལ་ཚུ་ཁ་སྐོང་འབད།
 - ཡིག་ཆ་སྤུས་ཚད་ཞིབ་འཚོལ་ཚུ་ཁ་སྐོང་འབད།

## བཟོ་རིག་གི་ཞིབ་ཕྲ།

### ལས་འབྲེལ་གྱི་བཟོ་རིག
 - **2x CLAUDE.md དང་མཐུན་པའི་ལས་འབྲེལ་ཚུ།**: ལམ་སྟོན་ཞིབ་འཚོལ་གྱི་དོན་ལུ་བསྐྱར་ཟློས།
 - **1x ནོར་འཁྲུལ་འཚོལ་ཞིབ་འབད་མི།**: འགྱུར་བ་ཚུ་ནང་ལུ་ ནོར་འཁྲུལ་གསལ་བཤད་འབད་ནི་ལུ་དམིགས་གཏད་འབད།
 - **1x ལོ་རྒྱུས་ཞིབ་འཚོལ་འབད་མི།**: git blame དང་ལོ་རྒྱུས་ལས་གནས་སྟངས།
 - **Nx ཡིད་ཆེས་ཀྱི་ཚད་གཞི་བརྩི་སྒྲིག་འབད་མི།**: དཀའ་ངལ་རེ་རེ་ལུ་རང་དབང་གི་ཚད་གཞི་བརྩི་སྒྲིག་འབད།

### ཚད་གཞི་བརྩི་སྒྲིག་གི་ལམ་ལུགས།
 - དཀའ་ངལ་རེ་རེ་ལུ་རང་དབང་ཐོག་ལས་ ༠-༡༠༠ བར་ལུ་ཚད་གཞི་བརྩི་སྒྲིག་འབད།
 - ཚད་གཞི་བརྩི་སྒྲིག་འདི་གིས་ དཔང་རྟགས་ཀྱི་སྟོབས་ཤུགས་དང་ཞིབ་འཚོལ་ལུ་བརྩི་མཐོང་བསྐྱེད།
 - ཚད་གཞི་ (སྔོན་སྒྲིག་གཞི་ ༨༠) འདི་གིས་ ཡིད་ཆེས་ཉུང་བའི་དཀའ་ངལ་ཚུ་སེལ་འཐུ་འབད།
 - CLAUDE.md དཀའ་ངལ་ཚུ་གི་དོན་ལུ་: ལམ་སྟོན་གྱིས་གསལ་བཤད་འབད་ཡོད་མེད་ཞིབ་འཚོལ་འབད།

### GitHub གཅིག་ཁར་བསྒྲིལ་བ།
'gh' CLI ལག་ལེན་འཐབ་སྟེ་:
 - PR ཞིབ་ཕྲ་དང་ diffs ཚུ་བལྟ་ནི།
 - གསོག་འཇོག་གི་གྲངས་གཞི་འཐུ་ནི།
 - git blame དང་ལོ་རྒྱུས་ལྷབ་ནི།
 - ཞིབ་འཚོལ་བསམ་འཆར་ཚུ་བཀོད་ནི།
