ഇതൊരു [`create-next-app`](https://nextjs.org/docs/app/api-reference/cli/create-next-app) ഉപയോഗിച്ച് ബൂട്ട്സ്ട്രാപ്പ് ചെയ്ത [Next.js](https://nextjs.org) പ്രോജക്റ്റാണ്.

## ആരംഭിക്കുന്നു

ആദ്യം, ഡെവലപ്‌മെന്റ് സെർവർ പ്രവർത്തിപ്പിക്കുക:

```bash
npm run dev
# അല്ലെങ്കിൽ
yarn dev
# അല്ലെങ്കിൽ
pnpm dev
# അല്ലെങ്കിൽ
bun dev
```

ഫലം കാണുന്നതിന് നിങ്ങളുടെ ബ്രൗസർ ഉപയോഗിച്ച് [http://localhost:3000](http://localhost:3000) തുറക്കുക.

`app/page.tsx` പരിഷ്കരിച്ച് നിങ്ങൾക്ക് പേജ് എഡിറ്റ് ചെയ്യാൻ തുടങ്ങാം. നിങ്ങൾ ഫയൽ എഡിറ്റ് ചെയ്യുമ്പോൾ പേജ് സ്വയമേവ അപ്ഡേറ്റ് ചെയ്യപ്പെടും.

Vercel-നായുള്ള ഒരു പുതിയ ഫോണ്ട് ഫാമിലിയായ [Geist](https://vercel.com/font) സ്വയമേവ ഒപ്റ്റിമൈസ് ചെയ്യാനും ലോഡ് ചെയ്യാനും ഈ പ്രോജക്റ്റ് [`next/font`](https://nextjs.org/docs/app/building-your-application/optimizing/fonts) ഉപയോഗിക്കുന്നു.

- [Next.js പഠിക്കുക](https://nextjs.org/learn) - ഒരു സംവേദനാത്മക Next.js ട്യൂട്ടോറിയൽ.
